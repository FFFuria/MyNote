# 神经网络
## 偏置参数
将感知机当中的阈值转换成 $b$ ，用是否大于0表示是否激活神经元，由此引入偏置参数 $b$
$y = \begin{cases} 0 & (b + w_1x_1 + w_2x_2 \leqslant 0) \\ 1 & (b + w_1x_1 + w_2x_2 > 0) \end{cases}$
$b$ 是被称为偏置的参数,用于控制神经元被激活的容易程度;而 $w1$ 和 $w2$  是表示各个信号的权重的参数,用于控制各个信号的重要性。
## 激活函数
*一般地,回  归问题可以使用恒等函数,二元分类问题可以使用 sigmoid 函数,  多元分类问题可以使用 softmax 函数。*
激活函数是在最终输出信号之前的函数，用于将输入信号的总和进行一定公式的转换输出
如下面函数中的 $h(a)$ 即属于激活函数的一种：
### 阶跃函数
$a = b + w_1x_1 + w_2x_2$ 
$y = h(a)$
阶跃函数是指一旦输入超过阈值,就切换输出的函数
### sigmoid函数
*适合分类*
$h(x) = \frac{1}{1 + \exp(-x)}$
向 sigmoid 函数输入 1.0 或 2.0  后,就会有某个值被输出,类似 h(1.0) = 0.731 . . .、h(2.0) = 0.880 . . . 
![[file-20251224125439567.png|430]]
![[file-20251224125450588.png|430]]
*导数用于求出参数*
导数往两边走时为0,我们称之为**梯度消失**
#### 缺点
1. 反向传播训练会出现**梯度消失**
2. 输出值区间（0,1），关于0不对称
3. 梯度更新在不同方向走得太远，使得优化难度增大与训练耗时
### Tanh函数
$\tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}} = \frac{\sinh(x)}{\cosh(x)}$
![[file-20251224144042753.png|430]]
解决了sigmoid输出值**非0对称**的问题
训练比sigmoid快，更容易收敛
![[file-20251224144200587.png|430]]
### ReLU函数
ReLU函数在输入大于 0 时,直接输出该值;在输入小于等于 0 时,输出 0。
**优点：**
1. 解决了梯度消失的问题
2. 计算更为简单
**缺点：**
* 训练过程可能出现**神经元死亡**
*神经元死亡：导数值为0,W和B不更新，神经元死亡*
*前面的是接近0,ReLu是直接=0*
### LeakyReLu
$f(x) = \begin{cases}x & \text{if } x > 0 \\\alpha x & \text{if } x \leq 0\end{cases}$
![[file-20251224150006465.png|371]]
**优点：** 解决了神经元死亡问题 *（处处有导数不为0）*
**缺点：** 无法提供正负输入值提供一致的关系预测 *（不同区间函数不同）*
### softmax函数
$y_k = \frac{\exp(a_k)}{\sum_{i=1}^{n} \exp(a_i)}$
#### 改进
![[file-20251105202159133.png|342]]
核心结论：**“在进行 softmax 的指数函数的运算时,加上(或者减去) 某个常数并不会改变运算的结果。**
我们想办法让**最大的指数尽可能小**。  
通过减去输入信号的最大值，将所有输入“拉低”到一个安全的、不会导致数值溢出的区间，从而解决了计算机在实现 Softmax 运算时的缺陷。
#### 被省略
*输出层的softmax一般会被省去，原因如下：*
**训练的目标**：训练的目标是**学习**。模型需要知道自己“错得有多离谱”，然后根据这个错误来调整参数（权重）。**需要损失函数**：为了量化“错得有多离谱”，我们需要一个损失函数（比如交叉熵损失函数）。**损失函数需要概率**：交叉熵损失函数的计算**必须**基于概率分布。它比较的是模型输出的概率分布和真实的标签分布之间的差距。原始的得分 【 3.0, 1.0, 0.2 】并不是概率，无法用来计算交叉熵损失。**Softmax提供概率**：Softmax的作用就是将这些原始得分转化成一个合法的、可微的概率分布 【0.836, 0.113, 0.051】，这样才能进行后续的损失计算和反向传播来更新模型。
### 非线性函数
阶跃函数和 sigmoid 函数两者均为 **非线性函数** 。sigmoid 函数是一条曲线,阶跃函数是一条像阶梯一样的折线
![[file-20251105202159128.png|612]]
**激活函数不能使用线性函数。**
线性函数的问题在于,不管如何加深层数,总是存在与之等效的“无隐藏层的神经网络”。
ex.考虑把线性函数 $h(x) = cx$ 作为激活函数,把 $y(x) = h(h(h(x)))$ 的运算对应3层神经网络。
但是同样的处理可以由 $y(x) = ax$
这一次乘法运算(即没有隐藏层的神经网络)来表示。
如本例所示,  使用线性函数时,无法发挥多层网络带来的优势

### 损失函数
*训练过程中产生*
近似于一种负反馈
**两大场景**
* 回归
	输出的值为连续的
* 分类
	输出结果为离散值
	算误差
#### 均方误差的损失函数
**预测值与真实值均为标量时：**
$\mathcal{L}(y, \hat{y}) = \frac{1}{2}(y - \hat{y})^2$
*1/2方便求导*
**批量数据（通用形式）：**
$\mathcal{L}(\mathbf{y}, \hat{\mathbf{y}}) = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2$
其中：
- yi​ 是第 i 个样本的真实值
- y^​i​ 是第 i 个样本的预测值
- n 是样本总数
以均方误差判断误差大小
借助**反向传播（梯度下降法）** 进行一个类似负反馈的调节
#### loss值
最后会得出一个趋于稳定的loss值，若loss值最后反而上升，我们会判断其为过拟合
### 梯度下降法
![[file-20251224163014781.png|449]]

$\partial J(w)$为损失函数，$\alpha$为学习率、以控制步幅
*采用参数更新原因：对于矩阵来说不用这种方法的话容易无解*

#### 步幅
输入层换区时**换的时候的步长**，例如4 * 4进行2的步幅，输出2 * 2，1则3 * 3
#### 填充
周围填充一圈0,保证边缘特征不丢失，提取边缘特征，保留边缘信息
同时可以避免特征图输出的不断缩小导致没有输入
![[file-20251225102537340.png|594]]
填充为P,步幅为S 
$OH = \frac{H + 2P - FH}{S} + 1$      |     $OW = \frac{W + 2P - FW}{S} + 1$
*你可以自己想象一下那个移动的过程，你就会知道为什么要减fh，因为最右（上）边的那个线最多只能走到原矩阵-FH（可以看成是距离），步幅可以看成是速度*
*计算出小数，部分模型会向上取整部分会向下*
